# 🏠 Origem Creative SLJR - Sistema de Gestão

## 📖 Sobre o Projeto
Sistema web completo para gestão de centro de acolhimento. Permite o controlo de crianças/utentes, gestão de funcionários, processamento de folha salarial e emissão de relatórios profissionais.

## ✨ Funcionalidades Principais
- 🔐 **Autenticação Segura:** Login via Supabase com roles (Admin vs Educador)
- 📊 **Dashboard:** Estatísticas em tempo real
- 👶 **Gestão de Crianças/Utentes:** CRUD completo
- 👥 **Recursos Humanos:** Gestão de funcionários
- 💰 **Folha Salarial:** Processamento automático
- 📄 **Relatórios:** Exportação PDF e CSV

## 🚀 Tecnologias
- React 18 + Vite
- Supabase (Auth + Database)
- TailwindCSS
- Vercel (Deploy)
