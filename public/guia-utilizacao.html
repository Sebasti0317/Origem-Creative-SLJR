1. ACESSO AO SISTEMA

URL de Acesso: https://origem-creative-sljr.vercel.app

Credenciais:

  • Email: Email institucional fornecido
  • Senha: Senha definida no convite inicial

Tipos de Utilizador:

  • 👑 Administrador Acesso total a todos os módulos
  • 👨‍🏫 Educador Acesso apenas a Crianças e Relatórios (limitado)

Primeiro Acesso:

  1. Verifica o email de convite do Supabase
  2. Clica em "Accept invitation"
  3. Define a tua senha (mínimo 6 caracteres)
  4. Faz login com email e senha

2. GESTÃO DE UTILIZADORES

Apenas Admin Menu lateral → Utilizadores

2.1 Criar Novo Utilizador

Método Recomendado (Via Supabase):
  1. Acede ao painel Supabase: https://supabase.com/dashboard
  2. Vai a Authentication → Users
  3. Clica em Invite user
  4. Preenche:
    • Email: Email institucional do novo utilizador
    • User metadata (JSON):
      {"nome": "Nome Completo", "role": "educador"}
      (usa "admin" apenas para administradores)
  5. Clica em Send Invite
  6. O utilizador receberá um email para definir a senha
Notas Importantes:
  • Educadores NÃO veem módulos de Funcionários, Folha Salarial ou Configurações
  • Admins têm acesso ilimitado
  • Cada utilizador deve ter um email único

2.2 Editar/Remover Utilizador

  1. Em Utilizadores, clica nos ... ao lado do utilizador
  2. Escolhe:
    • Edit user: Alterar nome ou role
    • Reset password: Enviar link de redefinição
    • Delete user: Remover permanentemente (cuidado!)

3. GESTÃO DE CRIANÇAS/UTENTES

Menu lateral → Crianças Todos

3.1 Adicionar Nova Criança/Utente

  1. Clica em + Nova Criança (canto superior direito)
  2. Preenche os campos obrigatórios:
    • ✅ Nome Completo (obrigatório)
    • Data de Nascimento
    • Data de Entrada
    • Nome do Encarregado
    • Contacto do Encarregado
    • Observações (informações relevantes)
    • Estado: Ativo/Inativo
  3. Clica em Guardar

3.2 Editar Informação

  1. Na lista de crianças, clica no botão ✏️ Editar da criança
  2. Atualiza os dados necessários
  3. Clica em Guardar Alterações

3.3 Imprimir Ficha Individual

  1. Vai a Relatórios → Módulo Crianças
  2. Usa os filtros para encontrar a criança
  3. Clica no botão 📄 na coluna "Ações"
  4. A ficha abrirá numa nova janela → Imprime ou guarda como PDF
Dica: A ficha adapta-se automaticamente:
  • Menores de 18 anos → "Ficha Individual da Criança"
  • Maiores de 18 anos → "Ficha Individual do Utente"

4. GESTÃO DE FUNCIONÁRIOS

Apenas Admin Menu lateral → Funcionários

4.1 Adicionar Novo Funcionário

  1. Clica em + Novo Funcionário
  2. Preenche:
    • ✅ Nome Completo (obrigatório)
    • Cargo/Função
    • Data de Admissão
    • Data de Nascimento
    • Contacto/Telemóvel
    • Email
    • Observações (notas de RH)
    • Estado: Ativo/Inativo
  3. Clica em Guardar

4.2 Imprimir Ficha do Funcionário

  1. Vai a Relatórios → Módulo Funcionários
  2. Localiza o funcionário
  3. Clica no botão 📄
  4. Imprime ou guarda como PDF
A ficha inclui: Dados pessoais, cargo, admissão, contacto, estado e espaço para assinaturas.

5. FOLHA SALARIAL

Apenas Admin Menu lateral → Folha Salarial

5.1 Processar Folha Mensal

  1. Clica em + Novo Registo Salarial
  2. Seleciona o Funcionário (lista dropdown)
  3. Preenche os valores:
    • Salário Base (obrigatório)
    • Subsídio de Férias (se aplicável)
    • Subsídio de Natal (se aplicável)
    • Outros Abonos/Bónus
    • Desconto INSS (calculado automaticamente ou manual)
    • Outros Descontos/IRS
  4. O sistema calcula automaticamente o Salário Líquido
  5. Define a Data de Pagamento
  6. Clica em Guardar

5.2 Imprimir Recibo Individual

  1. Vai a Relatórios → Módulo Folha Salarial
  2. Filtra por funcionário ou período
  3. Clica no botão 🖨️ ao lado do registo
  4. O recibo abrirá formatado (A5 horizontal)
  5. Imprime ou guarda como PDF
O recibo inclui:
  • Nome da instituição (das configurações)
  • Funcionário, cargo, mês/ano
  • Detalhe de vencimentos e descontos
  • Valor líquido destacado
  • Linhas para assinaturas

5.3 Visualizar Resumo do Mês

No topo da página Folha Salarial, vês 3 cards:

  • 💰 Salário Base Total
  • 📉 Total Descontos
  • ✅ Salário Líquido Total

6. RELATÓRIOS E EXPORTAÇÕES

Menu lateral → Relatórios

6.1 Tipos de Relatórios Disponíveis

Módulo Educador Admin Funcionalidades

6.2 Como Gerar Relatório

  1. Seleciona o Módulo (dropdown no topo)
  2. Aplica Filtros (opcionais):

    • Pesquisar: Nome ou cargo
  3. Clica em:

    • 🖨️ Gerar PDF: Lista completa formatada para impressão

6.3 Imprimir Registo Individual

Cada linha da tabela tem um botão de ação:

  • Crianças: 📄 → Ficha individual
  • Funcionários: 📄 → Ficha de funcionário
  • Folha Salarial: 🖨️ → Recibo salarial

8. BACKUPS E SEGURANÇA

8.1 Backup Manual (Recomendado Semanalmente)

Método 1: Exportar CSV de Cada Tabela

  1. Vai a Relatórios
  2. Para cada módulo (Crianças, Funcionários, Folha):
    • Aplica filtro "De" (data mais antiga) e "Até" (hoje)
    • Clica em 📥 Baixar CSV
    • Guarda numa pasta organizada (ex: Backup_2026-06-04)

Método 2: Via Supabase (Completo)

  1. Acede https://supabase.com/dashboard
  2. Vai a Table Editor
  3. Para cada tabela:
    • Clica em ... → Export data → CSV
    • Guarda localmente
Frequência Recomendada:
  • ✅ Semanal: Se houver muitos registos novos
  • ✅ Mensal: Mínimo obrigatório

8.2 Segurança de Dados

Boas Práticas:

  • 🔒 Nunca partilhes senhas
  • 🔒 Usa senhas fortes (mínimo 8 caracteres, letras + números)
  • 🔒 Faz logout sempre que terminares (botão "Terminar Sessão")
  • 🔒 Não deixes o computador desbloqueado com o sistema aberto

Níveis de Acesso:

  • Educadores: Só veem crianças (não acedem a dados financeiros)
  • Admins: Acesso total, mas com responsabilidade

9. RESOLUÇÃO DE PROBLEMAS

Problema Comum: "Não consigo entrar"

Causas possíveis:
  • ❌ Email ou senha incorretos
  • ❌ Email ainda não confirmado
  • ❌ Conta desativada

Solução:

  1. Verifica se o email está correto (sem espaços)
  2. Clica em "Esqueci a senha" no login
  3. Verifica o email (incluindo spam)
  4. Se não receberes, contacta o admin para reenviar convite

Problema: "Não vejo o botão X"

Causa: Provavelmente estás logado como Educador

Solução:

  • Educadores só veem: Dashboard, Crianças, Relatórios (crianças)
  • Para aceder a Funcionários/Folha, precisas de conta Admin
  • Contacta o administrador para verificar a tua role

Problema: "A imagem/logo não aparece"

Solução:

  1. Faz Hard Refresh: Ctrl + Shift + R (Windows) ou Cmd + Shift + R (Mac)
  2. Limpa o cache do browser
  3. Tenta noutro browser (Chrome, Edge, Firefox)

Problema: "Erro ao imprimir PDF"

Solução:

  1. Verifica se o popup blocker está desativado
  2. Permite popups para o site origem-creative-sljr.vercel.app
  3. Tenta noutro browser
  4. Se o erro persistir, exporta em CSV como alternativa

Problema: "Dados não aparecem no relatório"

Verifica:

  1. ✅ Os filtros de data estão corretos?
  2. ✅ O registo foi guardado corretamente?
  3. ✅ Tenta limpar filtros (botão "Limpar")
  4. ✅ Faz refresh da página
